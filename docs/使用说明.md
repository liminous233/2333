# 使用说明

## 本地打开
双击 `site/index.html` 即可（需要联网加载字体）。

## 改文字
所有文字都在 `site/data/content.js`。按里面的注释改，存档后刷新网页。
- 段落之间空一行；`**加粗**`
- `note` 是维的手写批注

## 换成自己的图片素材
1. 把图片放进 `site/assets/img/`（透明背景 PNG 最好）
2. 打开 `site/data/content.js`，在对应条目里填路径，例如
   `id: '01', icon: 'candle', image: 'assets/img/ev-candle.png',`
3. 刷新网页。留空 `''` 就继续用代码画的线稿

可以换的位置：
- 证物（12 件）：每件的 `image`
- 黑色太阳：`report.sunImage`（结案报告 + 莱恩的草稿纸都会用它）
- 工作证照片：`gate.photo`
- 人员档案三人：`personnel.main` 里每人的 `image`

## 调试
- 网址后加 `?assim=75`（比如 `index.html?assim=75#/journal/3`）可以直接把同化值设成 75，看各阶段效果：
  0–29 清醒 / 30–59 微恙 / 60–84 安宁 / 85+ 至臻
- 左下角「离开唱诗院」= 清空所有进度

## 三种结案报告怎么触发
- 先读完第 8 天日志，结案报告才会解封
- **A 正常结案**：同化值 < 60，且没有"点了香烛却没给手枪上膛"
- **B 白化报告**：同化值 ≥ 60，或点了香烛但没上膛
- **C 黑日**（叠加在 A/B 上）：读完第 6 天后，证物柜里会出现 #11 莱恩的草稿纸，打开它

## 背景音乐
目前是代码合成的低持续音。想换成真音乐：把 mp3 放进 `site/assets/audio/`，
然后在 `content.js` 顶部把 `music: ''` 改成 `music: 'assets/audio/文件名.mp3'`。

## 部署上线（Cloudflare Pages，免费）
1. 登录 dash.cloudflare.com → Workers & Pages → 创建 → Pages → 连接到 Git
2. 选 `liminous233/2333` 仓库，分支选 `main`
3. 框架预设：**None**；构建命令：**留空**；构建输出目录：**`site`**
4. 部署完会得到 `xxx.pages.dev` 网址
只发布 `site/` 文件夹，仓库里的 `docs/` 和其他文件不会上网。
