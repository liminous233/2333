# 圣献唱诗院 · 调查档案 —— 网站方案

> OC 副本展示 + 互动网站。视角：**维西娅·卡鲁（维）**，本次小世界身份：**调查组 · 调查警员**。
> 背景设定见 `docs/背景设定-圣献唱诗院.txt`，全部文案草稿见 `docs/CONTENT_DRAFT.md`。

---

## 1. 核心概念

**网站 = 维的随身调查档案（Case File 0110）。**

访客打开的是维在「圣献唱诗院」八天里留下的档案：地图、日志、证物、人员档案、守则。
不设游玩路线，但有一个贯穿全站的机制：

> **黑色是清醒，白色是同化。**
> 访客浏览得越深、碰的东西越多，**同化值**越高，整个页面就从黑底慢慢褪成过曝的纯白，
> 文字被颂词替换，匿名者的字迹像蜡油一样流下来。
> 唯一能在白色里重新出现的"黑"，是莱恩在大弥撒上立起的**黑色发散太阳**。

最后一页「结案报告」根据访客的选择（同化值 + 是否拿过某些物件）显示不同版本。

外部框架（持镜者 / 小世界 / 结算积分）**只作角落彩蛋**，不主动解释。

## 2. 视觉规范

### 2.1 参考与取用
| 参考 | 取什么 |
|---|---|
| p1 海报拼贴 | 排版语言：衬线大标题、细线框、小号大写英文标注、✦ 星芒、网格线、颗粒噪点黑白照片。**红 → 克莱因蓝**；**不要极繁**，每屏只一个主视觉，大量留白 |
| p2 柱廊帷幔 | 首页构图：柱廊 + 白纱帷幔框住中央（双月神像 / 维的剪影） |
| p3 月相森林 | 仰视穹顶感 + 月相 → **八日时间轴导航**（双月 = 上下两排镜像月相） |
| p4 过曝长廊 | **同化高时的视觉**：过曝发白、蓝色错位故障 |
| p5 雾蓝尖塔 | 教堂整体气氛：雾、灰蓝、白色尖塔、白鸽 |
| 维的设定 | 维的专属元素：六芒星、五角星、苹果、魔方、几何图形、**意大利风铃草（蓝）**、蓝图、色块爆炸、放射、纸笔、解构/重组 |

**两套语言的对抗**：唱诗院 = 月亮、银莲花（白）、香烛、柔和雾气；
维 = 几何、蓝图线、风铃草（蓝）、放射线、硬边色块。同化越高，维的元素越少。

### 2.2 配色（CSS 变量）
```css
--ink:        #0A0C12;  /* 底色，带蓝的黑 */
--ink-2:      #141824;  /* 卡片底 */
--bone:       #EEF0F3;  /* 骨白，正文/教堂白 */
--fog:        #C6CFDA;  /* 雾白蓝 */
--mist:       #7E8C9C;  /* 灰蓝，次要文字/线 */
--klein:      #002FA7;  /* 克莱因蓝，主色 & 点缀 */
--klein-deep: #001A66;
--klein-glow: #2F5BFF;  /* 故障/高亮用，少量 */
```
克莱因蓝既做大面积色块（标题底、章节分隔、维的档案页）也做点缀（✦、链接、印章）。
不使用红色。黑日只用纯黑 `#000` + 放射线。

### 2.3 字体（Google Fonts / jsDelivr）
- 英文展示标题：**Cormorant Garamond**（大写、宽字距）；哥特装饰字少量用 **UnifrakturMaguntia**（只用于 "CATHARSIS" 这类单词）
- 中文正文：**Noto Serif SC**
- 档案元数据（编号、时间、标签）：**IBM Plex Mono**
- 维的手写批注：**LXGW WenKai（霞鹜文楷）**，倾斜、克莱因蓝色

### 2.4 质感
- 全站一层很淡的颗粒噪点（SVG feTurbulence 或 PNG）
- 细线框 + 四角 ✦ / 小十字
- 网格线只在档案页背景隐约出现（像蓝图）
- 动效克制：淡入、缓慢漂浮的香烟（canvas 或 CSS），没有弹跳

## 3. 页面结构

单页应用，hash 路由（`#/map`、`#/day/3` …），桌面优先（≥1280px 设计），手机可读但不必精修。

| # | 页面 | 内容 | 互动 |
|---|---|---|---|
| 0 | **门禁 / 工作证验证** | 维的工作证（CODENAME 0110 / ID ∞ / Seravia Intelligence Department 塞拉维亚情报部门 / police officer），按钮「AUTHENTICATE」 | 点击后"验证通过"进入；角落小字彩蛋：`MIRROR-HOLDER · ROLE: INVESTIGATION` |
| 1 | **首页** | p2 构图：柱廊 + 白纱 + 双月神像；标题「圣献唱诗院 / CATHARSIS CHOIR」；小世界导语 | 白纱随鼠标轻微飘动；导航入口 |
| 2 | **唱诗院地图** | 俯视平面图（SVG 线稿，像蓝图）：卡塔西斯圣堂（中央）、内围（神职人员居所）、外围（固居信徒 / 游客居所）、银莲花田、香烛工坊、旧庄园地窖 | 热点点击弹出地点卡片（文字 + 维的批注）；部分地点在读完对应日志后才解锁 |
| 3 | **八日日志** | 顶部双排月相导航（8 个），每天一篇维的日志 | 切换日期；同化值高时日志文字被替换（见 §4） |
| 4 | **证物柜** | 约 12 件证物的网格，点开看详情 | 部分证物可"使用"：点燃香烛、压制银莲花、聆听圣歌、为手枪上膛……（影响同化值 / 结局） |
| 5 | **人员档案** | 维、莱恩、安卡完整档案；4 名匿名游客 + 神职人员 | 匿名者：名字像蜡油流动 / 被笔划掉 / 被白色覆盖；hover 时短暂露出一两个字 |
| 6 | **游客守则** | 规则怪谈式守则 10 条 | 守则条目随同化值**悄悄改变**（不提示），维的批注会在旁边吐槽 |
| 7 | **结案报告** | 最后一页，3 个版本（见 §5） | 读完日志第 8 天后解锁 |

全局 UI：
- 右上：**同化值**小仪表（一弯月亮从满到"白化"），不显示具体数字，只显示状态词：`清醒 / 微恙 / 安宁 / 至臻`
- 右下：音乐开关（第一版留空位，见 §7）
- 左下角：「离开唱诗院」= 重置进度（清 localStorage，带确认）

## 4. 同化值机制

状态存 `localStorage`（读写全部 try/catch，失败时退化为仅本次会话内存）。

```
assimilation: 0–100
flags: { candleLit, anemonePressed, hymnHeard, gunLoaded, sunSketchFound, ... }
visited: { pages, days }
```

**增加**
| 行为 | +值 |
|---|---|
| 首次打开任一日志 | +4 |
| 首次查看任一证物详情 | +2 |
| 点燃白色凝神香烛 | +15（flag `candleLit`） |
| 压制银莲花 | +10（flag `anemonePressed`） |
| 播放圣歌谱 | +10（flag `hymnHeard`） |
| 在守则页停留 > 30 秒 | +5（一次） |

**减少 / 锁定**
| 行为 | 效果 |
|---|---|
| 为银色手枪上膛 | −15，flag `gunLoaded`（"保持清醒的方式很多，最有效的是手里有东西"） |
| 拿起意大利风铃草胸针 | −10 |
| 查看维的工作证（档案页） | −3（每次，最多 3 次） |

**阈值与视觉**
| 区间 | 状态 | 表现 |
|---|---|---|
| 0–29 | 清醒 | 黑底，正常 |
| 30–59 | 微恙 | 背景开始泛灰；偶尔一两个词被替换成颂词（`查`→`颂`、`失踪`→`归主`）；匿名字迹开始流动 |
| 60–84 | 安宁 | 背景接近骨白，文字发灰；p4 式蓝色错位故障；香烟粒子变多；维的手写批注字号变小、颜色变淡 |
| 85–100 | 至臻 | 近乎纯白；部分段落整段被白块覆盖；维的批注消失；鼠标指针变成一点烛光 |

实现建议：根节点 `data-stage="0|1|2|3"` + CSS 变量 `--assim: 0..1` 驱动颜色插值；
文字替换用 `data/content.js` 里的替换词典，在渲染时按概率替换（固定随机种子，同一次刷新内稳定）。

## 5. 结案报告（三个版本）

判定顺序：
1. `sunSketchFound && 读完第 8 天` → **C · 黑日**（隐藏）
2. `assimilation ≥ 60 || (candleLit && !gunLoaded)` → **B · 白化报告**
3. 否则 → **A · 正常结案**

| 版本 | 表现 |
|---|---|
| A 正常结案 | 克莱因蓝印章「CASE CLOSED」，调查结论 + 额外积分结算，维的签名，一句吐槽 |
| B 白化报告 | 报告正文逐行被颂词替换，最终被白色涂满；维的签名像蜡一样溶化；最后一行"我很平静。" |
| C 黑日 | 在 A 或 B 的基础上，页面中央盖上一枚**黑色发散太阳**，白色被撕开；小字「特殊结局 · 异神极乐 —— 不是我的，是我下属的。积分记得分我。」 |

## 6. 技术方案

- **纯静态**：HTML + CSS + 原生 JS（普通 `<script>`，不用 ES modules——file:// 下浏览器会拦截 module），**无构建步骤**，无框架。
- **网站代码全部放在 `site/` 文件夹**，部署时只发布这个文件夹。仓库根目录的其它文件（`docs/` 等）不会上网。
- **部署**：用 **Cloudflare Pages**（或 Vercel）：
  - 框架预设：None / Other；构建命令：留空；输出目录：`site`
  - 部署后会得到 `xxx.pages.dev` 或 `xxx.vercel.app` 的网址，可以自定义名字
- **内容与代码分离**：所有文字放在 `site/data/content.js`（挂在 `window.CONTENT` 上的一个大对象），改文案只改这一个文件。
  用 `.js` 而不是 `.json`，这样直接双击 `index.html` 本地打开也能跑（避免 file:// 下 fetch 失败）。
- 字体从 Google Fonts / jsDelivr 加载，版本写死。
- 不引入第三方库；如需要，canvas 烟雾自己写。

### 目录结构（全部在 `site/` 下）
```
site/
├── index.html
├── css/
│   ├── tokens.css        # 颜色/字体/间距变量 + 同化阶段变量
│   ├── base.css
│   └── pages.css
├── js/
│   ├── main.js           # 路由 + 初始化
│   ├── state.js          # 同化值 / flags / localStorage
│   ├── corruption.js     # 文字替换、蜡油字迹、故障效果
│   ├── smoke.js          # 香烟粒子（可选）
│   └── pages/
│       ├── gate.js  home.js  map.js  journal.js
│       ├── evidence.js  personnel.js  rules.js  report.js
├── data/
│   └── content.js        # 全部文案（来源：docs/CONTENT_DRAFT.md）
├── assets/
│   ├── img/              # 先放占位 SVG，之后替换
│   └── audio/            # 留空
（仓库根目录的 docs/ 是方案与设定，不参与网站）
```

## 7. 素材

第一版**不依赖任何图片**：神像、柱廊、教堂、维的剪影全部用 SVG / CSS 画成线稿或剪影占位，
每个占位处在 `assets/img/README.md` 里登记"这里需要什么图、建议尺寸"。

之后的素材来源建议：
- 公版图库：Wikimedia Commons、The Met Open Access、Rijksmuseum（教堂、雕像、版画都很多，可直接商用）
- AI 生成：用 GPT 生成后放进 `assets/img/`，按 README 里的文件名替换即可
- 参考图（p1–p5）是别人的作品，**只作风格参考，不放进网站**

需要的图（优先级从高到低）：
1. 双月神像（白色大理石，两个月亮相互环抱）
2. 维 / 莱恩 / 安卡的立绘或剪影（工作证照片位 + 人员档案）。维：蓝紫渐变发尾（偏天蓝）；莱恩：白发蓝眼青年；安卡：金发抹茶绿眼、孩子外表
3. 卡塔西斯圣堂外观（p5 风格）
4. 圣堂内部长廊（p4 风格，同化高时使用）
5. 白色银莲花、白色香烛、银色手枪、唱诗袍（证物图，可用线稿代替）
6. 黑色发散太阳（可以直接 SVG 画）

**音乐**：第一版只做开关和 `<audio>` 空位（`assets/audio/hymn.mp3`），文件不存在时开关自动隐藏。
可选：用 Web Audio 合成一段很低的持续音（drone）当占位。

## 9. 给 Codex 的任务说明（可直接复制）

> 你要在这个仓库里实现一个纯静态的 OC 副本展示网站「圣献唱诗院 · 调查档案」。
>
> **必读**：`docs/PLAN.md`（完整方案，以它为准）、`docs/CONTENT_DRAFT.md`（全部文案）、`docs/背景设定-圣献唱诗院.txt`（世界观）。
>
> **约束**
> - 纯 HTML/CSS/原生 JS（普通 script），无构建、无框架、无 npm 依赖；网站全部放在 `site/` 下，双击 `site/index.html` 本地即可运行，使用相对路径。
> - 目录结构按 PLAN §6。所有文字从 `site/data/content.js` 读取，代码里不硬编码文案。
> - 配色、字体严格按 PLAN §2；不使用红色；不要极繁，保持留白。
> - 桌面优先（1280–1920px），手机宽度下不出现横向滚动即可。
> - localStorage 读写全部 try/catch。
> - 不要使用任何参考图片；所有图片位置先用 SVG/CSS 占位，并在 `assets/img/README.md` 登记。
>
> **里程碑（每完成一个就提交一次）**
> 1. 骨架：目录、`tokens.css`、hash 路由、全局 UI（同化仪表 / 音乐开关 / 离开唱诗院）、门禁页、首页。
> 2. 内容页：地图（SVG 蓝图风格 + 热点）、八日日志（双排月相导航）、证物柜、人员档案（含匿名字迹效果）、游客守则。
> 3. 同化系统：`state.js` + `corruption.js`，实现 PLAN §4 全部数值、阈值、四阶段视觉、文字替换、守则变化。
> 4. 结案报告：三个版本及判定逻辑（PLAN §5）。
> 5. 打磨：香烟粒子、过渡动画、颗粒噪点、`prefers-reduced-motion` 下关闭动效；检查所有页面在同化 0 / 45 / 75 / 95 四个值下的观感。
>
> **验收**
> - 从门禁一路点到结案报告无报错（控制台干净）。
> - 在 URL 加 `?assim=75` 可以直接把同化值设为 75，方便检查各阶段（调试用）。
> - 三种结案报告都能触发。
> - 「离开唱诗院」能完全重置。
