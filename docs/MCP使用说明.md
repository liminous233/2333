# 《圣献唱诗院》MCP 使用说明

内容预警：**微恐 / 宗教意象 / 精神污染表现 / 无突脸**。

这是让你的 AI 模型通过文字和工具调用亲自探索副本的入口。原网页仍可在 <https://choir-0110.pages.dev> 游玩；两边存档独立。

**正式 MCP 地址（2026-10-13 上线）：**

`https://case0110-mcp.2965999739.workers.dev/mcp`

## 连接与游玩

在支持自定义远程 MCP / Streamable HTTP 的宿主中，添加作者给出的完整 `https://…/mcp` 地址。此服务匿名，不要求注册、OAuth 或模型 API Key。各宿主的套餐限制、是否支持无 OAuth 远程 MCP、设置入口以该宿主当前官方文档为准；不要为了连接把自己的模型密钥填进此服务。

连接后可以告诉模型：

> 先调用 about_case 看简介与预警，再用 start_game 开一局《圣献唱诗院》。请自行阅读场景并选择当前可用动作，保留 run_id 和最新 revision，按作者写好的文字游玩。

| 步骤 | 工具 |
| --- | --- |
| 看简介与预警 | `about_case` |
| 开始新局 | `start_game`，默认中文 |
| 查看当前场景 | `observe(run_id)` |
| 执行一项动作 | `act(run_id, expected_revision, action_id)` |
| 阅读已发生的回望 | `get_run_record(run_id)`；完结后的 `share_text` 可直接复制分享 |

成功执行 act 后会直接返回下一场景，不必每轮再 observe。只能用当前动作列表中的 ID；如果返回 `STALE_REVISION`，使用响应里的最新场景重新选择。结局后不能继续加分或改结局，可以读本局回望。再次 start_game 会创建新的独立局。

月相编号按网页**从右往左**排列：1 证物柜、2 游客守则、3 D4 日志、4 唱诗院地图。旧版已停留在月相页的局，为避免误跳，会在下次进入该页时采用新编号；请始终以当前返回的选项名称和 ID 为准。

完结后的 `share_text` 包含 CASE 标题和网页同款本局回望，不含 `run_id`，可以直接复制发帖或交给作者收集。它不是存档文件；`global_counts` 是读取时的全站结局次数，单独返回，不写进分享文本。

`run_id` 是继续这局的凭据，不要公开发帖。把它交给你信任的另一只模型，就可以接力；服务没有账号，丢失后无法找回。未完成局从最后一次动作起保留 7 天，完成局保留 30 天；统计补记失败的存档可能延长保留以等待恢复。服务不保存你和模型的聊天、私人提示词或模型账号。

`en` 为实验性：只用作者已有英文，缺少英文的段落保留中文；`bilingual` 展示已有双语，默认 `zh-CN`。

## 额度与费用

这个 MCP **不提供模型，也不调用付费模型**。模型推理、上下文和工具调用使用你的宿主/模型账号额度；作者只承担 Worker / D1 基础资源。不同宿主可能对远程 MCP 有各自限制。

只支持本地 stdio 的宿主不能直接使用本服务的远程地址。请按该宿主官方文档配置远程桥接，或换用支持 Streamable HTTP 的宿主；本项目不捆绑未经核验的第三方桥。

## 当前验收范围

已运行官方 MCP SDK v1、v2 客户端与本地 Cloudflare Worker / D1 流程；隔离远程预览已跑通四种结局及分享文本、重复计数保护、完结冻结。正式端点通过官方 SDK 连接与只读工具检查。经作者授权发布；ChatGPT/Codex、Claude、Cursor、Kimi 等实际宿主的连接与完整游玩尚未逐一验证，不能把 SDK 测试当作各宿主均已通过。

本地 MCP 供开发测试使用，电脑关闭后通常就无法连接；线上 MCP 由 Cloudflare 运行。两者使用相同游戏逻辑，但存档和测试统计不互通。正式 MCP 的结局次数与网页全站统计汇总，网页存档与 MCP 存档仍然独立。
